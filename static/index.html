口径说明
后复权HFQ 历史价格按公司行动向后复权；只用于BOLL。
RLY宣告股息率 以报告期分组，最近年度末期已公告派息 + 最近中期已公告派息，换算每股并除以未复权股价；本年度中期待定可沿用上期并单独提示。
历史分位 约10年的每周 RLY 同口径回溯估算，缺少有效公告日或样本不足显示「—」。
低位共振 只有周线与月线同时处于「中」或「中下」才亮星；「下」不计入，日线不参与。切换来源会自动重算；任一周期缺失显示「待计算」，不会误判成「否」。
数据来自公开第三方接口，可能延时、缺失或被限流。财报及股息率不能替代投资判断。 本工具本地运行，不需要账号或 API Key。图示数据不会当作行情导入。
