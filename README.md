# 股息率观察与财报分析工具 V10：42只股票（新增双核电）及最近财报自动展示

## 本版新增（完整项目，非单独补丁）

- **42只股票的最近定期报告自动索引**：浏览器打开后后台独立更新；列表新增「最近财报」列，显示 *2026三季报/半年报/年报* 等实际检索到的报告期、正式披露日期和官方 PDF 链接。
- **选股自动展示财报**：点击左侧股票，右侧自动显示最新财报卡片、报告名称、报告期、披露日期、来源和直接 PDF 链接；无需先点“查看最新财报”。
- **工具内 PDF 预览**：点击“页面内预览”，后端从巨潮资讯 `static.cninfo.com.cn` 拉取经校验的官方 PDF；也可点“打开官方 PDF”在新标签浏览或下载。PDF 大于 30MB、被限流、无有效文档或浏览器不支持时，使用原始链接。
- **最新财务指标**：新浪财务利润表中的营收、归母净利润、净利润、营业利润、每股收益（仅源中存在的字段）。显示各项同比（若接口提供），并标注财务报表自身的报告期。**如财务指标的报告期不同于最新巨潮 PDF，会提示不能混用**。
- **批量刷新按钮**：页面上方「↻ 更新42只最新财报」；实时进度与行情/BOLL 刷新任务独立；首次打开自动请求，之后报告索引12小时内复用缓存。已核验缓存保留更新时间；联网失败会标记错误，不以旧年报冒充最新。
- **报告真实性校验**：巨潮公告按季报、半年报、年报分类索引；报告期从公告标题推断，非公告日期。只接受观察池股票代码对应官方公告和含真实 `adjunctUrl` 的 PDF；排除“摘要、业绩预告、审计报告、取消及编制通知”等非完整定期报告。

## Windows 启动

1. **关闭旧版本占用 8765 端口的启动窗口**。
2. 将此 ZIP 完整解压到**新文件夹**，例如 `D:\DividendWatchV10`；不要在 ZIP 内直接启动。
3. 双击 `START_HERE_V10.cmd`（也可用 `启动工具_Windows.bat`）。需要 Python 3.10+，首次安装需要互联网。
4. 浏览器打开 `http://127.0.0.1:8765`，界面会自动开始同步42只股票最近财报索引。
5. 如果同步失败，查看“财报索引”状态/列表“读取失败”，点击「↻ 更新42只最新财报」手动重试。可以使用顶部「更新全部 42 只」刷新行情和股息率，两类任务互相独立。
6. 启动异常：脚本保留菜单不自动退出；输入 `D` 生成 `DIAGNOSIS_V10.txt`，亦可查看 `INSTALL_LOG.txt` 或 `RUN_LOG.txt`。

## 口径与注意事项

- **BOLL未更改**：日/周/月 HFQ 后复权价格，中轨20周期SMA、上下轨±2σ（总体标准差）、五档上/中上/中/中下/下；月和周都是中或中下才是低位共振。五档中间阈值仍为 V7 的 ±1σ 约定，原图作者未披露精确阈值。
- **RLY未更改**：仍按已公告末期/中期分红÷未复权现价计算，不将已经实施的TTM当RLY。
- **最新财报报告期≠公告日期**。例如 2026 年三季报对应报告期 `2026-09-30`，公告可能于2026年10月发布。以实际链接元数据为准，不写死。
- **财报PDF和财务摘要来自不同官方/第三方接口**。新浪指标更新可能落后于巨潮最新原文。未拿到指标时仅展示PDF，不填造数值。
- **数据接口为非官方开放调用方式**，易受反爬、限速和源站格式调整影响。当前构建环境未能联网进行巨潮PDF的端到端校验；需在你的 Windows 联网电脑上验证接口是否正常返回。
- **自动刷新不等于服务器向你持续推送**。打开本地工具时启动索引核对，按需手动刷新；程序停止后不在后台运行。
